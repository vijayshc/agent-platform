# Built-in skills

Skill packages placed here ship with the platform and are available to every
agent that requests them by id (see `SKILL_SETUP.md`). Packages installed
through the Skills UI live in `uploads/maf-skills` and shadow these.

This directory is empty by default: the platform is content-agnostic. The
example skill packages used by the sample agents live in
`platform_samples/skills/` and are registered by `scripts/feed_samples.py`.
